# ● GameStream

Стрим мобильных игр без водяных знаков. Два режима:

| Режим | Что делает телефон | Что делает ПК |
|---|---|---|
| **YouTube** | Захватывает экран + звук и сам стримит на YouTube | не нужен |
| **На ПК** | Захватывает экран + звук игры и по Wi‑Fi шлёт в OBS | Микрофон, вебка, оверлеи, отправка на YouTube |

## Сборка через GitHub (можно с телефона)
1. Создай репозиторий на github.com, загрузи туда `GameStream.zip` (не распаковывая).
2. *Add file → Create new file*, имя `.github/workflows/build.yml`, вставь текст из файла
   `GameStream/.github/workflows/build.yml`, нажми *Commit changes*.
3. Вкладка **Actions** → дождись зелёной галочки (~5–8 мин) → внизу **Artifacts**:
   - `GameStream-phone-apk` — приложение для телефона
   - `GameStream-PC-exe` — программа для Windows

Если загружаешь распакованную папку с ПК — шаг 2 не нужен, файл уже внутри.

## Режим «YouTube»
1. YouTube Studio → Создать → Начать трансляцию → вкладка «Трансляция» → скопируй **ключ трансляции**
   (первый раз YouTube может включать трансляции до 24 часов).
2. В приложении: «YouTube», вставь ключ, выбери качество → «Начать стрим» → открой игру.

## Режим «На ПК»
1. На ПК: запусти OBS и **GameStream PC**.
2. В OBS: Сервис → Настройки сервера WebSocket → включить. В GameStream PC нажми «Добавить телефон в OBS».
3. На телефоне: «На ПК» → «Найти ПК автоматически» → звук «Только звук игры» → «Начать стрим».
4. Картинка появится в OBS. Микрофон и вебку добавь в OBS, стрим запускай из OBS.

Если Windows спросит про доступ OBS к сети — «Разрешить». Лучше Wi‑Fi 5 ГГц, ПК — кабелем к роутеру.

## Во время игры
Красная плашка поверх игры: таймер эфира, битрейт, значок микрофона.
- **Тап** — микрофон вкл/выкл
- **Долгое нажатие** (1 сек) — завершить стрим
- **Перетаскивание** — подвинуть

## Технологии
Android: RootEncoder (MediaCodec H.264 + AAC, RTMP/SRT). ПК: Python, obs-websocket v5.
